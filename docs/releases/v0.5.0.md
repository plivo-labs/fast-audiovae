# v0.5.0

Build 1 adds the validated NVIDIA CUDA decoder to the 0.5.0 release. It combines the narrow first projection, fused depthwise convolution with Snake, and fused late matrix operations. Original FP32 weights are retained.

CPU remains the default. Apple and NVIDIA GPU execution are optional and selected with `load(device="gpu")`. The Apple, AMD and Intel CPU native libraries are unchanged.

```sh
python -m pip install 'fast-audiovae[gpu]==0.5.0' --find-links https://github.com/plivo-labs/fast-audiovae/releases/expanded_assets/v0.5.0
```

Omit `[gpu]` for a CPU-only installation. NVIDIA requires Linux x86-64, CUDA-enabled PyTorch 2.14.x and an Ampere or newer GPU. Already on 0.5.0? Reinstall the package with `--force-reinstall --no-deps`; pip otherwise considers the installed version satisfied.

Measured over 60 complete multilingual recordings, totaling 535 seconds, with two timing rounds and completed CPU audio. All 45,894 numerical comparisons passed, including silence, quiet audio, expressive recordings, continuous streaming and the previous compiled control. All 27 CUDA tests passed. These are public API timings, including validation and history rollback support.

Apple ARM, Linux x86 and portable build 1 wheels are included. The original wheels remain available; pip prefers build 1 for an otherwise identical wheel tag. `SHA256SUMS` covers both wheel builds and the updated source archive. The original `v0.5.0` Git tag is preserved; [build 1 source](https://github.com/plivo-labs/fast-audiovae/tree/v0.5.0-build1) identifies the updated code.
